# Marslander — Creative & Production Agency Website

Новый сайт для креативного продакшн-агентства полного цикла **Marslander** ([marslander.ru](https://marslander.ru/)), созданный в строгом соответствии с фирменным стилем бренда, цветовой палитрой и материалами официальной презентации проектов.

## 🚀 Стек технологий (JavaScript / React)
- **Язык**: JavaScript (ESNext / JSX)
- **Фреймворк**: React 19 + Vite 6
- **Стилизация**: Tailwind CSS v4 с кастомной темой (Mars Deep Crimson `#a71e28`, Space Dark `#111b1e`, Glassmorphism, космические орбиты)
- **Иконки**: Lucide React
- **Анимации**: HTML5 Canvas (интерактивные орбитальные траектории и частицы)

## 🎨 Фирменный стиль и палитра
- **Mars Red**: `#a71e28` (акцентный бордово-красный оттенок Марса)
- **Space Dark**: `#090e10` / `#111b1e` (глубокий космический темный петроль)
- **Чистый белый**: `#ffffff` для типографики и векторного логотипа
- **Элементы космоса**: тонкие орбитальные контуры, мерцающие звезды, планетарные точки

## 📦 Разделы сайта
1. **Header / Navbar**: Фиксированное полупрозрачное меню с оригинальным логотипом, быстрой навигацией, телефоном, кнопкой скачивания презентации и вызовом формы заявки.
2. **Hero**: Главный экран с интерактивным Canvas-фоном орбит, слоганом, ключевыми метриками (10+ лет, 40+ топ-брендов, 500k+ тиражи, 100% контроль), кнопками перехода в портфолио и скачивания PDF.
3. **Бренды & Партнеры**: Интерактивная витрина и фильтр по категориям заказчиков (Bosco, ГУМ, Первый канал, Альфа-Банк, Газпромбанк, ВТБ, Skolkovo Golf Club, Правительство Москвы, КХЛ, Артек, Vesper, Moschino, MaxMara, BORK, Т-Банк и др.).
4. **О компании (About)**: Манифест «Поехали!», философия, принципы работы и интерактивные карточки 5 ключевых направлений.
5. **Работы из презентации (Portfolio)**: Полноценная галерея с 30+ кейсами, фильтрами по 6 категориям, поиском, тегами, детальными описаниями и полноэкранным модальным окном (lightbox).
6. **Производственные мощности**: Описание технологических процессов (3D-конгрев, горячее фольгирование, УФ-печать, шелкография, вышивка, литье медалей и брелоков, лазерная резка).
7. **Отзывы**: Раздел с отзывами топ-менеджеров и продюсеров ключевых клиентов (Bosco, Альфа Private, Первый канал, Skolkovo, БРИКС, AliExpress).
8. **Контакты («Есть контакт!»)**: Все контакты (+7 985 240 0060, +7 910 494 8700, info@marslander.ru, Ружейный пер. 2А), форма заявки с предзаполнением выбранного кейса, ссылками на мессенджеры и Яндекс Карты.
9. **Footer**: Юридическая информация, быстрые ссылки, скачивание презентации.

## 🛠 Запуск и сборка

### Установка зависимостей:
```bash
npm install
```

### Запуск локального сервера разработки:
```bash
npm run dev
```

### Сборка готовой production-версии:
```bash
npm run build
```

Готовый билд находится в папке `/dist`.
